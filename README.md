# Manipulation with MongoDB & Quotes Web-Scraping

This project solves two tasks:
1. Creating and manipulating MongoDB databases using Python.
2. Web scraping quotes from various authors from a website.

## Description

### Task 1: Working with MongoDB
In this task, a MongoDB database was created, and functionality for manipulating data stored in this database was developed. Operations such as adding, retrieving, updating, and deleting data were implemented.

### Task 2: Web Scraping Quotes
Quotes and their respective authors were scraped from a website using web scraping libraries. All collected data was converted into JSON format and stored in the MongoDB database.
